# 演示冻结清单

目标是稳定展示一条完整的**模拟**闭环，而不是宣称真实酒店、真实设备或实时 MATD3 控制。

## 冻结版本应展示

1. 人物选择后输入“我想休息”，选定起床时间，展示主 Agent → Experience Agent → 能源规则 → Space Execution Agent → Harness 的实际调用轨迹。
2. 确认后，虚拟灯光、空调、窗帘发生变化且界面读回状态。
3. 点击“模拟已入睡”触发首个夜间步骤；该按钮不是睡眠传感器。
4. 注入模拟室温变化，展示一次自动调整与活动记录。
5. 快进或自动播放到渐进唤醒；另跑一次服务后点击停止，展示未执行步骤取消、设备不恢复。
6. 空间页展示在线规则能源建议和离线固定日 MATD3 对比卡，并明确两者不在同一控制路径。

## 上台前

- 后端固定 `LIVINGMIND_DEMO_LOCAL_HOUR=20`；若演示模型模式，确认 `.env` 里的密钥与网络可用，否则切回规则模式。
- 在“我的”页点“准备演示”，检查界面顶部模式标识与设备状态都已重置。
- 先跑一遍规则模式完整流程；模型模式只作为增强证据，超时会降级为规则而不影响主线。
- 真机前必须按 [device-build.md](device-build.md) 记录 iPad / Android 结果；网页端通过不等于真机通过。

## 冻结后不做

- 不修改结果文件以追求更漂亮的能源数字。
- 不在演示前接入新的厂商 SDK、数据库、认证、真实语音或后台定时器。
- 不把前端 Mock、虚拟设备、模拟入睡、离线数据说成真实接入。
