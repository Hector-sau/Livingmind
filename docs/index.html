复现这一晚

在项目根目录运行以下命令，打开终端显示的本机地址。默认家庭场景使用 Python 3.9 或以上版本，无需安装依赖或配置模型密钥。

python3 backend/family_demo.py

打开「场景模拟器」并选择「妈妈到家」。试着输入「我今晚还要看书，客厅亮一点，卧室先别动」，然后查看建议和执行后的回读。
