# LivingMind v1.0.0

**Versioned source and demonstration release · 正式源码与演示版本**

LivingMind turns everyday needs into coordinated home services with explicit confirmation, controlled execution, feedback and stopping.

LivingMind 将生活需求转化为可确认、可执行、可调整、可停止的居住空间服务。本版本用于产品演示、工程复现和技术评审，不是应用商店安装包或公网生产系统。

## Included 本版内容

- **平板优先 App**：React Native / Expo / TypeScript，兼容手机布局，提供对话、空间设备、场景和人物入口。
- **Agent 与记忆**：主 Agent 编排、Experience Agent 结构化语言理解、Space Execution Agent 动作映射；支持人物偏好隔离、会话澄清、LangGraph 规划与明确的规则降级。
- **受控执行**：规划不改变设备，多设备方案须确认；策略与有界授权在服务端检查，每次动作重新验证有效性；执行结果经过回执和状态回读。
- **持续服务**：休息、模拟入睡、环境变化、自动调整与渐进唤醒；停止使旧计划和后续动作失效，但已在途动作可能完成。
- **故障恢复**：统一动作账本、独立持久化虚拟网关、后台未知结果核对；查询原动作回执，不盲目重发设备控制。
- **工程交付**：FastAPI / PostgreSQL / Redis / Docker Compose；OpenAPI 生成 TypeScript 契约；数据库迁移与 Outbox 事件处理。Redis 用于协调，Kafka 未接入。
- **能源研究**：独立离线家庭能源仿真、Actor 权重和固定日对比数据；App 展示结果，在线控制使用规则。

## Download 下载内容

推荐下载 GitHub Release 中的 `LivingMind-v1.0.0-source.zip`。它由发行提交通过 `git archive` 导出，保留 App、后端、测试、契约、锁文件、Compose、CI、能源模块与正式说明，排除交接文件和历史开发报告。Git 仓库保留完整开发历史。

发行页面另提供发布说明、`release-manifest.json` 与 `SHA256SUMS`。Manifest 记录精确提交、CI 地址和源码包摘要。下载到同一目录后可使用 `shasum -a 256 -c SHA256SUMS` 核对。

本版本不附带 APK / IPA、Docker 预构建镜像、模型服务密钥或本地数据库数据。源码包中的研究权重不是大语言模型权重。

## Run 运行

环境：Docker 与 Docker Compose、Node.js 22（CI 基线）。不使用 Docker 的单进程后端可使用已验证的 Python 3.11 / 3.12。

解压后在项目根目录启动完整虚拟设备环境：

```bash
export LIVINGMIND_GATEWAY_TOKEN="$(openssl rand -hex 32)"
export LIVINGMIND_ORCHESTRATOR=langgraph
docker compose -f compose.yaml -f compose.gateway.yaml --profile replicas up -d --build
```

主 API 为 `http://127.0.0.1:8000`，第二 API 为 `http://127.0.0.1:8001`。默认规则规划不需要模型密钥。

另一终端启动客户端预览：

```bash
cd apps/mobile
npm ci
cp .env.example .env
```

将 `.env` 中的 `EXPO_PUBLIC_API_BASE_URL` 设置为 `http://127.0.0.1:8000`，然后运行：

```bash
npm run web -- --clear
```

规则/模型配置、原生 development build、局域网连接与关闭环境的完整说明见根目录 `README.md`。不把浏览器验收当作原生真机验收。

## Validation 验证

发布前要求精确发行提交通过 GitHub Actions 的三组后端、前端、契约与 Docker 浏览器端到端检查，共六项 Job。最终提交、运行地址和结果写在 Release 页面及 `release-manifest.json`，不以历史绿灯替代发行提交的验收。

此前完整代码基线已验证：全栈后端 278 通过 / 1 跳过、前端 106 项、浏览器端到端 29/29，以及迁移和契约一致性。最终发布采用该提交新跑出的结果；CI 的模型请求使用替身，不产生真实模型调用证据。

## Scope and known limitations 边界与已知限制

- 设备为虚拟设备，睡眠与夜间推进为模拟事件/时钟；尚未接入 SpaceMind、真实厂商设备、睡眠传感器或智能音箱。
- iOS / Android JavaScript / Hermes 导出已有验证，但原生安装包、真机界面和设备端语音识别尚未验收。
- 账户/PIN 为原型机制，不提供生产级认证；仅运行于本机或可信局域网，勿使用默认凭据公开部署。
- 停止不自动恢复设备原值；在途动作可能完成；当前验证不构成物理设备 exactly-once 或生产高可用保证。
- 记忆是结构化偏好与会话状态，不是向量 RAG 或自动人格学习。
- 能源学习策略基于 MATD3 框架、配置 N=1、固定日、美元/华氏度参数；购电下降不是总耗电下降，也不代表真实节能收益或跨日期泛化。当前实现未启用目标动作平滑和延迟 Actor 更新，不声称完整标准 MATD3 实现。
- 依赖风险记录中仍有未解决公告；本次不进行未经兼容性验证的大版本升级，也不宣称零漏洞。详见 `docs/dependency-risk.md`。
- 尚未添加统一 LICENSE，本次不新授予 MIT / Apache 等许可；第三方依赖和研究来源记录保持原样。
