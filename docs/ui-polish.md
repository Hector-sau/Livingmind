# 视觉整理清单（第 8 节 C 项）

执行时机：⑥b 对话外壳完成之后、演示打包之前。目的是让演示更像产品，不改变任何业务行为。产品形态目标见 `AGENT-HANDOFF.md` 第 12 节：四个入口（对话 / 空间 / 场景 / 我的），原始活动细节只在证据面板显示。

## 原则

- 只改 `apps/mobile/theme/`、`components/`、`features/`；不动 `services/`、`packages/`、后端。
- 美化不能把“前端模拟 / 规则计划 / 虚拟设备 / 规则降级”这些来源标注藏起来。
- 开始前先在平板横屏（1180×820）和手机竖屏（390×844）各截一组基线截图，完成后对比。
- 图标用 Expo 自带的 `@expo/vector-icons`。动效允许引入 `react-native-reanimated`（Expo SDK 57 自带支持），用于对话流入场、卡片展开、数值滚动；全部尊重系统“减弱动态效果”设置。
- 视觉参考（只看布局与动效思路，不搬代码）：GitHub 上 Home-App-Expo（Expo 智能家居示例）、react-native-reanimated 官方示例、GitHub 话题 smart-home（TypeScript）。

## C 完成情况（2026-09-17）

已完成：天蓝色明亮配色（用户指定）、LivingMind Logo（横版用于头部，图形部分用于 App 图标、启动图、AI 头像）、`@expo/vector-icons` 统一图标、渐变主按钮与按压回弹、卡片柔和阴影、消息淡入、运行中呼吸点、设备数值条动画、骨架屏加载、场景卡图标与时间线、我的页渐变头卡、手机头部压成一行。动效用 React Native 自带 `Animated` 实现并尊重“减弱动态效果”，没有引入 Reanimated（减少原生依赖风险）。

未做：空态插画、信息类提示 3 秒自动淡出、右栏独立滚动比例微调。

## 0. ⑥b 之后的现状（C 之前）

页面结构已经是四个入口：`features/shell/AppShell.tsx`（导航与头部）、`chat/`（对话流、计划卡、结果卡、服务状态条、输入区）、`space/`、`scenes/`、`me/`。当前视觉是可用的基础样式：导航图标用的是 emoji 占位，Logo 是一个蓝色方块占位，没有动效。C 步骤就在这些文件上美化，不再改结构。

## 1. 视觉基础（先做，影响全局）

| 项目 | 现状 | 改成 |
|---|---|---|
| 配色 | 只用了蓝色 | **天蓝色明亮干净**（用户指定）：主色 #0284C7、强调 #0EA5E9 / #38BDF8、背景 #EAF6FF→#F7FBFF 渐变；运行中/成功绿；模拟/警告琥珀；停止/错误红；品牌色取自 Logo（青 #18C7C8、叶绿 #55C97A、暖黄 #F6C453） |
| 字体层级 | 各级字号接近 | 页面标题 26、卡片标题 18、正文 15、说明 13；每屏一个最强焦点 |
| 间距与圆角 | 所有卡片一致 | 主卡片（计划、设备）加大内边距，次要卡片收紧；圆角统一 16 |
| 图标 | 无 | 灯泡、雪花/温度、窗帘、人物、停止、刷新 |
| Logo | 仅文字 | LivingMind 横版 Logo（透明底、不拉伸），右侧保留模式标签 |

## 2. 各组件

| 组件 | 要改的点 |
|---|---|
| 头部 | Logo + 空间名；模式标签改为小圆点 + 文字 |
| 人物选择 | 首字头像圆圈；选中态用蓝色左边条；偏好用三个小图标 + 数值 |
| 需求输入 | 输入框加大；灰色麦克风占位图标并标注“语音后续接入”；平板上按钮与输入框同行 |
| 休息计划 | 动作列表改为“图标 + 设备 + 目标值 + 结果标签”；来源标签放标题右侧；确认按钮固定卡片底部 |
| 休息服务 | 运行中加缓慢呼吸的绿色圆点；停止按钮改为红色描边 |
| 设备状态 | 瓦片加图标；进度条按设备用不同颜色；“可能已过期”时整块灰色遮罩 |
| 场景执行记录 | 人话时间线（“22:10 室温升高，空调降到 24°C”），左侧时间线圆点；原始活动细节移到“我的 → 证据面板” |
| 证据面板 | 默认关闭；打开后显示原始活动记录、来源、耗时、traceId；样式可以朴素 |
| 对话流 | 用户气泡右侧，AI 回复左侧；计划卡与结果卡是嵌在对话里的卡片；新消息淡入并自动滚动到底部 |
| 提示条 | 错误保持红色常驻；信息类 3 秒后淡出 |
| 空态 / 加载态 | 空态用大图标 + 一句引导；加载态用骨架屏 |

## 3. 布局与动效

- 平板横屏：左栏 55%（人物、需求、计划），右栏 45%（服务、设备、动态），右栏独立滚动。
- 手机竖屏：设备状态改为横向滑动三张卡；服务动态默认折叠。
- 动效只做三种：卡片淡入、数值变化滚动、按钮按下缩放；全部尊重系统“减弱动态效果”设置。
